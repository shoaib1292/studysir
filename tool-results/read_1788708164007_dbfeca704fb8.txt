     1→# Study Sir Platform - Work Log
     2→
     3→## Project Vision (from user)
     4→"Study Sir" — a Facebook-style tuition marketplace connecting students/parents with teachers.
     5→
     6→**Core flows:**
     7→- Students/Parents post tuition requests (subject, fee range, timing, location)
     8→- Teachers "approach" a tuition post by spending **coins** (cost scales with tuition fee weight)
     9→- After spending coins, chat unlocks between teacher & student/parent
    10→- Student/parent decision buttons: **Hire (Select) / Reject / Block / Report**
    11→- Coin rules:
    12→  - Reject BEFORE any chat → coins refunded to teacher
    13→  - Reject AFTER chat started → NO refund
    14→  - No reply from student/parent → auto-refund after 10 days
    15→  - Hire → coins consumed by platform
    16→  - After decision (hire/reject) → chat locked (no further conversation)
    17→- Teachers can post Courses (fee, duration, timing, format) and sell Digital Goods (price)
    18→- Wallet: coins balance, buy coins, coin history, money wallet
    19→- Sidebar: Wallet, Messages, Tuition, Digital Store, Buy Coins, Coins History, Money Wallet, Monetize Program, Monetize Reviews, Settings
    20→
    21→## Design references (from Figma Web.zip)
    22→- Header: "StudySir" bold blue logo, search bar "Search Tuion", avatar
    23→- Nav icons: Home, Tuition (cap), Board/Courses, Store, Bell, Chat
    24→- Feed cards:
    25→  - Tuition post: avatar, name, green "Hire" chip, star rating, title, description w/ blue highlights, See More, details (Language/Subjects/Qualification/Fee Range/Timing), footer Like/Review/Hire/Live Chat
    26→  - Course post: green "Hire Teacher" chip, cover poster, Language/Subject/Duration/Timing/Class duration/Classes per week/Format/Fee, footer Like/Review/Question/Join Request
    27→  - Digital goods: image, title, rating, description, price, "Seller: X", footer Like/Review/Share/Download

    29→- Chat screen: blue header (back, avatar, name, last seen), bubbles, "Today" chip, message input + send; bottom action row: Select/Hire (blue), Reject (red), Block (red), Report (red)
    30→- Teacher profile: cover photo, avatar w/ online dot, name, subtitle, Hire Teacher btn, rating, Connection count, Likes; tabs Posts / Time Availability / Reviews
